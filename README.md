# clock2.0
一、功能介绍：
  1.使用ESP32网络功能，使用NTP协议进行联网
  2.使用RGB灯代替时分秒针来显示时间
  3.使用OLED屏幕来显示更精确的时间，日期及温湿度传感器获得的温湿度
  4.为防止灯光在晚上会造成光污染，利用光线传感器来获取环境亮度，在亮度较暗时自动关闭灯光
  5.长按按键可切换到下一页，第一页是时间及温湿度，第二三四页为今明后天的天气预报（白天及夜间天气，最高最低温度），第四页长按重新回到第一页
  6.语音控制（中科四平的语音识别模块），“前进”切换到下一页，“后退”切换到上一页
  7.每月的15日15时15分15秒自动校准时间，每小时的0分0秒自动更新天气
二、硬件清单：
  1.esp32物联半
  2.温湿度传感器
  3.按键
  4.OLED屏幕
  5.光线传感器
  6.语音识别模块
